# Contract AI System

An AI-powered contract review application that analyzes contracts across Legal, Compliance, Finance, and Operations domains.

## Live Demo

**Deployed Application:** https://contract-ai-system.onrender.com

## GitHub Repository

https://github.com/pooja383971/contract-ai-system

## Technologies Used

- Python
- Streamlit
- Groq API
- PDF Processing
- AI-powered Contract Analysis

## Key Features

- Upload PDF contracts.
- Analyze legal risks and obligations.
- Review compliance-related issues.
- Identify financial risks.
- Analyze operational risks.
- Generate structured AI findings.

## Deployment

Deployed using Render with GitHub integration.

## Disclaimer

AI-generated findings are for informational purposes and should not replace professional legal advice.
